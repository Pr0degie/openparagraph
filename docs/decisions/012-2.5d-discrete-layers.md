# 012 — 2.5D view uses discrete FNA layers, not continuous PCA z

**Status:** accepted (refines ADR 009)
**Date:** 2026-05-31

## Context

ADR 009 introduced one Three.js renderer for 2D / 2.5D / 3D, with the 2.5D view
defined as "FA2 x/y map + semantic z (pipeline PCA z)". Once the pipeline started
emitting a continuous PCA `z` per node, the 2.5D view used it
(`base.fz = n.z / POS_SCALE`).

In live use the continuous-z 2.5D read as a dense, disorganised depth cloud — the
user's words: "Kuddelmuddel", and "man kann durch die Kugeln durchschauen". The
earlier, discrete-layer 2.5D (one z-plane per FNA main_group, the old fallback
`zFromMainGroup`) was strongly preferred: "tausendmal besser … ich mochte dass es
paar Ebenen gab und alle Knoten in einer Reihe bei der Ebene waren".

## Decision

The **2.5D view stacks nodes into discrete planes, one per FNA main_group**
(`zFromMainGroup(n) = (main_group − 5) × layerGap`). The continuous PCA `z` is no
longer used for 2.5D. It stays in the data (`nodes.json`), reserved for a possible
future genuine "semantic 3D" mode.

`web/src/main.ts`: `base.fz = mode === '2.5d' ? zFromMainGroup(n) : 0`. The layer
gap is live-tunable via the tuning panel (ADR 014).

## Alternatives considered

- **Continuous PCA z (the ADR 009 intent)** — semantically richer but visually
  cluttered; rejected on direct user feedback.
- **A toggle between layered and continuous** — extra UI for a mode nobody asked
  to keep; deferred. Easy to add later since the PCA z is still in the data.

## Consequences

- 2.5D is now purely structural (FNA grouping), not semantic. The semantic signal
  lives only in colour and, potentially, a future 3D mode.
- Records a reversal of part of ADR 009; ADR 009 otherwise stands.
- User preference captured in auto-memory (`feedback-25d-discrete-layers`).
